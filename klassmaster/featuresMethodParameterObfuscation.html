Obfuscation using Method Parameter Obfuscation

The Zelix KlassMaster™ Method Parameter Obfuscation functionality obscures method parameter lists by replacing all parameters with a single Object[] parameter. This functionality is intended to be used in conjunction with Name Obfuscation.

For example, the following list of method signatures:

String getUserId()
List   getCustomerOrders(Customer, Date, Date, long)
int    add(int, int)

could be obfuscated to the following:

String a(Object[])
List   a(Object[])
int    a(Object[])

Please see the Method Parameter Obfuscation Tutorial for more detail.
