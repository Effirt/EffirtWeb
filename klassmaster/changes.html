Version 27.0 release 0 (20 Sep 2026)

  • Preliminary release validating support for Java 27.
  • Enhances the Flow Obfuscation functionality to make its transformations more random.
  • Enhances the Method Parameter Obfuscation functionality to make its transformations more random.
  • Enhances the obfuscated name list functionality to support Java escape sequences.
  • Improves support for the handling of OSGi blueprint XML.
  • Changes the default of the ZKM Script obfuscate statement's methodParameters parameter from keepVisible to delete.

  • Note that this release will not run reliably on IBM Semeru Runtimes that make use of the Eclipse OpenJ9 VM due to a suspected JIT compiler bug.

Version 9.0 release 0 (26 Jul 2017)

  • Implements preliminary support for the Java 9 bytecode including Java modules (i.e. Project Jigsaw).
  • Introduces the optional Method Parameter Change functionality. It further "hardens" the existing enhanced String Encryption and Reference Obfuscation functions to make them more difficult to reverse.
  • Introduces the Ignore Missing References functionality which allows you to specify class, method and field references that Zelix KlassMaster™ should ignore if it cannot find.
  • Introduces the Remove Method Calls functionality which allows you to specify method calls that Zelix KlassMaster™ should remove if possible. This is intended to allow you to remove optional method calls such as debugging statements.
  • Enhances the ZKM Script obfuscate statement by introducing the uniqueClassNames parameter. When set to true, this option tells Zelix KlassMaster™ to not reuse unqualified class names across packages. This option can be useful when a framework uses unqualified class names as identifiers in annotations or XML.
  • Enhances the ZKM Script obfuscate statement by introducing the new "keepMethodParametersIfNotObfuscated" and "keepVisibleIfNotObfuscated" values for the existing localVariables and methodParameters parameters respectively. These options allow method parameter names to be retained even in methods which are not public or protected.
  • Enhances the ZKM Script open statement to allow the "skipping" and "unskipping" of top level class and XML files.
  • Enhances the ProGuard Configuration Translate tool to make use of the new Ignore Missing References and Remove Method Calls functionality.
  • Enhances the ZKM Script unexclude statement to allow package names to be unexcluded.
  • Now requires a Java 8 (i.e. JDK 1.8) JVM to run but still can process Java bytecode back to Java 1.1.
  • Other minor changes and bug fixes.

    • contained at least one corrupt Inner Class Attribute table entry and
    • contained at least one valid Inner Class Attribute table entry.
    Note that, amongst other things, Zelix KlassMaster™ treats Inner Class Attribute table entries as corrupt if they contain inner class names that do not start with the outer class name followed by a '$' character.
  • has improved (but still fallible) handling of bytecode containing calls to the method Class.forName().
